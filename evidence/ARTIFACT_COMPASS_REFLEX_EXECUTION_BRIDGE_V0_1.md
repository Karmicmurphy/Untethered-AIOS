# Artifact Compass — Reflex Execution Bridge V0.1

## Bounded question and current truth

Can the verified Python Kernel, Attention Governor, AuditLog, and SQLite
Computation Memory execute and reuse one deterministic non-AI task with exact
capability authority, or is another runtime/framework required?

Campaign 1 already proved routing, hashes, dependency invalidation, FakeModel,
and the target Windows hardware. Kernel V0.2 already provides process state,
structured capability requests, exact resource scopes, child grant subset, and
persistent receipts. No unresolved external fact could change the direct
stdlib/SQLite implementation, so another web research pass was stopped.

## Classification and stack position

| Candidate | Exact stack position | Decision | Campaign 2 treatment |
|---|---|---:|---|
| Kernel V0.2 process/capability path | kernel authority | KEEP | Own spawn, grant check, invocation, failure, and receipts. |
| Attention Governor V0.1 | model-governor layer | KEEP | Select REFLEX/CENTRAL_AI/OWNER_GATE without executing. |
| SQLite Computation Memory | computation-memory layer | KEEP | Extend only with hash-verified JSON result storage and explicit reuse predicates. |
| AuditLog + SQLiteProcessTable sink | evidence layer | KEEP | One durable route/capability/computation chain. |
| FakeModel | central-AI test boundary | KEEP | One deterministic escalation; no real model/provider. |
| Small cheap-handler registry | handler resolution layer | TEST | Prove one stable contract and exact Kernel capability; no grant authority. |
| request-normalizer-v1 | deterministic cheap-handler layer | TEST | Prove useful bounded execution, reuse, and dependency recomputation. |
| Generic plugin/agent framework | replacement handler platform | REJECT | Adds loading/authority complexity and solves no verified gap. |
| Filesystem/network/process capability | authority expansion | REJECT | Normalization needs none. |
| AERA, NARS, Tsetlin, WiSARD, vector DB, Redis, broker | replacement runtime/memory | REJECT | No measured need; outside Campaign 2. |
| Rust, WASM, containers, GPU, cloud/provider SDK | runtime expansion | REJECT | No fit for this deterministic in-process proof. |
| More handlers, Workshop capability, owner UI | later capability/product layers | DEFER | Exactly one handler and no Workshop work in Campaign 2. |
| Real Model Gateway | later model adapter | DEFER | FakeModel remains the only central test double. |

## Proof plan and decision

TEST is adopted only if focused tests prove exact and wrong-scope grants,
first-run execution, identical reuse with no handler/model call, dependency
recomputation, unrelated reuse, FakeModel escalation, OWNER_GATE, durable
receipt kinds, and benchmark savings; full regressions and rollback must pass.

Direct successor selected: one Kernel-owned REFLEX execution bridge with
`request-normalizer-v1`. No dependency, provider, model, UI, Workshop,
database service, permission, or deployment broadening is allowed.
