# Artifact Compass — Cognitive Substrate V0.1

## Reality and better question

Verified base: live-read validation commit
`acf981b15de4b098659e0f74b28465d288a97e0b`, preserving Kernel V0.2 and
Workshop Read Adapter V0.1 while excluding the owner-surface candidate.

Measured target remains Windows 10, AMD A4-class four logical processors,
approximately 7.45 GB RAM, Python 3.12, and embedded SQLite. The missing
Campaign 1 capability is:

> Can the current Python/SQLite stack deterministically decide whether work
> deserves computation, preserve reusable dependency results, and prove those
> decisions without adding a model, provider, framework, vector database, or
> new Workshop authority?

Current repository evidence already establishes the official Python/SQLite
runtime and licensing fit. The campaign precludes platform selection, and no
unresolved external fact could change the bounded implementation. Another
public-research pass was therefore stopped as credit-inefficient.

## Direct successor and proof

Implement only:

1. stable architecture/data contracts;
2. local deterministic Attention Governor V0.1;
3. rollback-journal SQLite Computation Memory V0.1;
4. a synthetic FakeModel benchmark covering the required work classes.

Proof requires exact routes, explainable hash-linked receipts, A-to-B-to-C
invalidation with D reusable, focused/full tests, measured CPU/wall/memory,
zero provider/network calls, no dependency change, and zero Workshop changes.

No broadening statement: no later cognitive system, owner surface, Workshop
write/deployment, model/provider, semantic memory, framework migration, or
runtime expansion is included.
