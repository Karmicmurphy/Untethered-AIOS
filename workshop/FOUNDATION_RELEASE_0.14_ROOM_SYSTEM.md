# Foundation Release 0.14.1 — Explorable Room System

Release 0.14.1 is a visual-navigation patch over the accepted Release 0.14 Workshop. It adds no worker, provider, model, execution engine, database migration, or new room capability.

The first root view is Sanctuary. Enter Workshop opens Crossroads. Crossroads represents the twelve destination rooms from the owner-supplied floor plan, with fixed truthful capability labels. Existing working tools remain on their existing routes and selectors. Every individual room receives a direct Crossroads return.

The active backend, SQLite schema 13, source authority, hash gates, plan approval, result approval, receipts, exports, recovery, rollback, and service routes remain authoritative and unchanged.

The source floor-plan image informed the spatial hierarchy but is not deployed as a runtime asset. The live map uses lightweight HTML, CSS gradients, and linework suitable for older Windows hardware.
