TWIS HOLO - CLEAN PACKAGE

1. Move the extracted TWIS folder directly to C:\TWIS
2. Open C:\TWIS
3. Double-click START_TWIS.bat
4. KEEP THE BLACK WINDOW OPEN
5. The FlashRiver ZIP path is copied automatically
6. In Twis Holo, open Recover
7. Click the FlashRiver ZIP path box and press Ctrl+V
8. Leave the expected SHA-256 unchanged
9. Click Import FlashRiver package once

Use FLASHRIVER.zip. Do not use FLASHRIVER_RECEIPT.json.
Do not use Import Folder for FlashRiver.

FLASHRIVER REVIEW VIEW
After FlashRiver imports successfully, click "Review in My Work". The dedicated Review screen groups all imported records, shows source evidence, and lets you save local review states and notes. It does not modify the original FlashRiver ZIP.
