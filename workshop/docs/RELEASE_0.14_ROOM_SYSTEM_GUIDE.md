# Release 0.14.1 Room System — Owner Guide

The Workshop now opens at **Sanctuary**, a quiet entry surface with five bounded actions. **Enter Workshop** opens **Crossroads**, the primary room navigator.

Crossroads shows the real capability class of every destination. Write, Images, Music, and Explore retain their deployed governed builders. Control Room, My Work, Recover / Machine Room, Modules, Settings, and New Idea use existing system behavior. Video and Build remain visibly Foundation Only.

Use **← Crossroads** at the start of any room to return to the navigation hub. Refresh preserves an explicit room URL. Opening the root URL without a room hash returns to Sanctuary and does not resume a state-changing operation.

Control Room retains the existing local status deck and provides access to the existing Talk room. Recover / Machine Room retains the existing receipts, job history, rollback, interrupted-work, conflict, validation, database-health, and recovery surfaces. No authority or API moved.
