# Release 0.12 Owner Guide — Visual Brief Builder

Open **Images**, then choose **Open Visual Brief Builder**.

Select up to four registered text sources, enter visual notes, or use both. The job must contain at least one selected source or nonblank notes. Select one fixed visual-purpose preset and complete only the controls useful to the concept; optional groups can remain collapsed and omitted fields become clearly labeled unresolved creative decisions.

Choose **Prepare hash-bound plan** and review the exact source identities, hashes, order, preset, temporary-note identity, and permissions. Approve the plan with a note, generate the deterministic brief, then review and approve or reject the result separately.

An approved result can be saved as one inactive `visual-brief-draft`. Saving does not generate an image, contact a provider, attach, activate, publish, promote, or modify a source. TXT, Markdown, and JSON export are separate explicit actions. Exported prompts are clean manual-use copies and are never submitted automatically.

My Work can filter and reopen Visual Brief outputs. Refresh and browser restart recover the project-scoped governed job. Rollback removes only the unchanged saved draft created by that job; registered sources and audit receipts remain.
