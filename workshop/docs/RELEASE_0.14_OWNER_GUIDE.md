# Release 0.14 Owner Guide — Workshop Shell

The Workshop now opens as a compact local control deck. The left room rail preserves the existing rooms and labels each one honestly as an active tool, active room, foundation-only area, recovery-ready area, or system room.

The status band shows the active project, selected room, local companion availability, database-open availability, selected builder source, pending approval count, and recovery state. `UNKNOWN` and `NOT EXPOSED` mean the existing UI API does not provide enough evidence for a stronger claim.

Home summarizes existing project artifacts, registered sources, inactive drafts, pending governed work, the current release, and the latest exposed project receipt. The capability grid opens existing rooms only; it does not add tools.

Recover summarizes existing governed job and receipt state. Red quarantine treatment appears only for a real stale job or an actual failure/conflict reported by an existing workflow. It is not a simulation.

**Split: ON/OFF** changes only layout. It does not affect sources, jobs, approvals, receipts, or saved work. All layout changes are immediate, visible focus is preserved, and reduced-motion settings disable animation.
