# Release 0.11 Owner Guide — Evidence Compare

Open Explore and select **Open Evidence Compare**.

1. Select between two and eight registered text sources. The workspace shows selected count, identity, shortened hash, and a Remove control.
2. Choose a comparison focus and enter optional instructions.
3. Prepare and review the ordered, hash-bound plan.
4. Add an approval note and approve the plan.
5. Generate the deterministic comparison workspace.
6. Review and separately approve or reject the result.
7. After approval, optionally save one inactive `research-comparison-draft` or explicitly export TXT, Markdown, or JSON.
8. Use My Work → Evidence Compare outputs to reopen the saved artifact and inspect parent source IDs, approval state, export history, and rollback state.
9. Roll back only the unchanged draft created by that job.

Evidence Compare does not perform internet research, fetch URLs, call a model or provider, or generate semantic conclusions. Exact whole-text and line overlap are textual facts only. Complete semantic registers manually or by deliberately using a separately exported prompt.
