# Release 0.14.2 New Idea Room — Owner Guide

Open **New Idea** from Sanctuary or Crossroads. Enter an idea title, add an optional quick note, and optionally choose one of the Workshop's real projects.

- **Unassigned** keeps the idea semantically unassigned while using the active project as the required local storage scope.
- **Save as inactive idea** writes one `DRAFT` idea artifact and a normal artifact receipt. It does not run or approve anything.
- **Cancel** clears the unsaved form and returns to Crossroads without creating data.
- Saved ideas appear under **My Work → Inactive ideas** and can be reopened in the New Idea room.

The room never calls an AI provider, launches a worker, publishes, activates, or creates a project. The inherited **New project** action remains available in Control Room and is separate from this room.
