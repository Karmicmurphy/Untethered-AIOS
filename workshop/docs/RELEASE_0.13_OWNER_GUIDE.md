# Release 0.13 Owner Guide — Song Production Brief Builder

Open **Music**, then choose **Open Song Production Brief Builder**.

Select up to four registered text sources, enter temporary music notes, enter owner lyrics or fragments, or combine them. Choose one fixed song-purpose preset and complete only the production controls that matter. The Workshop requires at least one nonempty input.

Prepare the hash-bound plan, review it, and approve it with a note. Generate the deterministic brief, then review and approve or reject the result separately. Approval does not save, export, play, submit, publish, attach, or activate anything.

After result approval, **Save inactive draft** creates exactly one `song-production-brief-draft`. My Work can filter and reopen it. TXT, Markdown, and JSON export are separate explicit actions to the bounded local builder export folder. **Roll back draft** removes only an unchanged draft created by that job; sources and audit receipts remain.

Owner lyrics are reproduced exactly. Missing musical choices are labeled **Unresolved musical decision**. This tool does not generate or play music and does not call a model or provider.
