# Release 0.15 Owner Guide — Video Production Brief Builder

Open **Sanctuary → Crossroads → Video**, then choose **Open Video Production Brief Builder**.

Select up to four registered sources and/or enter owner video notes. Choose one fixed video-purpose preset, complete only the useful planning groups, and prepare the plan. Plan approval does not approve the result. After approving the plan, generate the deterministic brief, review it, and separately approve or reject it.

An approved brief can be saved once as an inactive `video-production-brief-draft`, reopened through My Work, and exported explicitly as TXT, Markdown, or JSON. Rollback removes only the unchanged draft created by that job. Registered sources remain unchanged.

This room is a planning station, not a renderer. It never generates, renders, uploads, publishes, or submits video and never calls a provider.
